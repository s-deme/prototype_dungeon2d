LANTERN DEPTHS — asset and runtime inventory

Game-specific source, names, rules, text and UI styling are contained in this project.
The repository contains no imported third-party character art, image packs, music or
sound recordings. Map and character graphics are generated as UI Toolkit elements
and text glyphs. Text uses Japanese fonts installed in Windows (Yu Gothic, Meiryo or MS Gothic);
font files are not redistributed. Sound effects are synthesized sine-wave tones
generated by this project's TurnAudio code.

Runtime: Unity 6000.3.22f1, including UI Toolkit and the bundled Mono runtime.
Unity's original third-party notice file is included unchanged as
Unity-Third-Party-Notices.txt. It is the notice inventory shipped with this Unity
Editor version and may list components beyond those used by this game.

Development and tests use Unity Test Framework and NUnit; the game does not require
the Unity Editor or the test tools to be installed by the player.

This inventory does not assign a new license to the game-specific source or assets.
Third-party components retain their respective notices and license terms.
